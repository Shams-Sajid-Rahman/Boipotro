# Seed cover images

Downloaded from the [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers)
(Internet Archive), by ISBN, for demo/sample data only. File name = the listing's ISBN.

Fallbacks found by title search on Open Library (cover is a different edition or the title page):
`9780321811059`, `9781119320913`, `9789339219666`, `9781119491637`, and `9780134414232`
(12th-edition title page, ISBN 9780321696724).

Book covers are the publishers' copyright. Fine for a local demo; replace with your own
photos (or remove) before running a public site.
